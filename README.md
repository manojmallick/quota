# QUOTA

QUOTA is an extraction-survival game prototype. Collect scrap to meet the quota while managing noise and avoiding the pursuing agent.

## Run

Open `project.godot` in Godot 4.x and press Play. Controls: **E** extract scrap, **Space** sprint, **C** quiet/crouch, **R** restart.

## Project files

- `Main.gd`: quota tracking, noise meter, agent behavior, and game state.
- `Main.tscn`: game scene and quota HUD.

## Requirements

Godot 4.x. No environment variables or external services are required.
